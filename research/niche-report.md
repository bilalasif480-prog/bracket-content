## Patterns so far
- Big account (digitaldesignkw) wins on consistency: one brand colour, one design system, Arabic-first.
- Everyone posts seasonal greetings; nobody in this set is making educational or QA/bug-style content. That gap is where Bracket's bug mascot reels stand out.
- Price-tier posters (kuwaitnext) are the one format that sells directly. Instamake can't invent prices, so only use Bracket's real fixed-scope/fixed-price angle.
- Client proof (brandlift: reviews, our clients, talking heads) is the main trust builder. Bracket has no testimonials to use, so don't fake any.
- Highlights organised by service make the profile easy to scan.

- Problem-first hooks ("Does your website show these red flags?") are the strongest educational format seen (webdevelopmentkuwait). Bracket can do the same with QA: "5 bugs your site has right now".
- Offer-poster with price (chrisansgroup, 550 KD vs 1200 KD) got 1 like. Price posters are not a proven engagement driver.

## Ideas for instamake (don't copy, adapt)
1. Reel: "services in 15 seconds", one highlight per service, in the bracket mascot style.
2. Carousel: "what's in a fixed-price package", using only what's on the site.
3. Avoid plain seasonal greetings unless tied to a QA/web joke (Ramadan launch deadline reel).
4. Profile: add highlights per service (QA, web build, handover).
5. Carousel (AR+EN): "Does your site have these red flags?" told as the bug mascot catching 5 QA issues (slow load, broken mobile menu, dead link, missing Arabic RTL, form that does not submit). Hook adapted to Bracket's QA angle.
6. Reel: bilingual "Arabic RTL bugs" spot-the-bug game; bug character hides in a screenshot, viewer finds it.
7. Reel: "Your website never sleeps; does it ever get tested?" with bracket mascots doing a night-shift QA check.
